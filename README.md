# StudyPDF

강의 PDF 위에 페이지별로 필기하고, 슬라이드를 넘기는 순간에 맞춰 녹음을 나눠 저장하는 웹 노트.

**데모:** https://qkrwoalsHerb.github.io/studyPDF/

## 해결한 문제
50분 강의 녹음은 한 덩어리로 남아 "이 슬라이드 설명이 몇 분쯤이었지?"를 찾기 어렵다.
StudyPDF는 **PDF 페이지를 녹음의 색인**으로 쓴다. 3쪽을 보는 동안의 소리는 3쪽에, 다시 돌아와 들은 보충 설명은 3쪽의 두 번째 구간으로 쌓인다. 녹음을 누르면 그 녹음이 시작될 때 쓰던 필기 위치로 커서가 이동한다.

## 기능
| 기능 | 설명 |
|---|---|
| 전체 녹음 + 구간 표시 | 녹음은 끊기지 않고 파일 하나로 저장되고, 페이지를 넘길 때마다 그 위에 구간(시작·끝) 표시만 남김 |
| 짧은 구간 정리 | 기준 시간(기본 2초, 1~10초) 안에 넘긴 페이지는 구간으로 만들지 않음 (소리는 전체 녹음에 남음) |
| 이어 붙이기 | 구간으로 만드는 대신 직전 구간의 끝을 늘려 포함시키는 옵션 |
| 필기 위치 연결 | 녹음 구간 클릭 시 당시 필기 위치로 이동 + 재생 |
| 글자별 색 | 6가지 기본색 + 색상 선택기, 굵게 |
| 저장 위치 | 내 컴퓨터 폴더 또는 Google Drive, 최근 위치 10개 |
| 홈 정렬 | 생성순 / 수정순 / 이름순 |

## 기술
클라이언트 전용 (서버 없음) — PDF.js, MediaRecorder API, IndexedDB, File System Access API, Google Identity Services, Google Drive API v3 (`drive.file`)

## 저장 결과물
```
바탕화면/동아리/대학교/1-2학기/자료구조/자료구조 3주차/   ← 앱의 폴더 트리와 같은 구조
├── lecture.pdf
├── audio/ take_20261012_1653_xxxx.webm   ← 전체 녹음 1회분 = 파일 1개
├── index.json   ← 페이지·구간(시작/끝)·필기 위치·자막 색인
└── notes.html   ← 페이지별 필기 모음
```

## 배포
1. 저장소 `studypdf` 생성 (Public) → `index.html`, `config.js`, `README.md` 업로드
2. Settings › Pages › Branch `main` / `/ (root)` → Save

## Google 로그인 설정 (제작자 1회)
사용자는 "Google로 로그인" 버튼만 누른다. 제작자가 한 번만 설정한다.
1. console.cloud.google.com → 새 프로젝트
2. API 및 서비스 › 라이브러리 → **Google Drive API** 사용
3. OAuth 동의 화면 → 외부 → 앱 이름 StudyPDF, 범위 `drive.file`
4. 사용자 인증 정보 › OAuth 클라이언트 ID → 웹 애플리케이션
   - 승인된 JavaScript 원본: `https://qkrwoalsHerb.github.io`
5. 발급된 ID를 `config.js`의 `window.STUDYPDF_CLIENT_ID = ''` 따옴표 안에 붙여넣고 `index.html`과 같은 곳에 올리기 (한 번만 하면 이후 index.html을 새로 올려도 유지됨)
6. 동의 화면이 "테스트" 상태면 등록한 테스트 사용자만 로그인 가능 → 누구나 쓰게 하려면 "앱 게시"

## 동작 환경
Chrome·Edge 권장 (폴더 선택 지원). Firefox·Safari는 내 컴퓨터 저장 시 zip으로 내려받음.

## 2차 업데이트

- **화면 구성**: 필기 중에는 상단(제목·PDF)과 하단(녹음)이 저절로 접히고, 화살표로 다시 펼칩니다. 녹음 패널을 펼치면 왼쪽에 구간 목록, 아래에 전체 녹음 타임라인이 나타납니다. PDF·필기·녹음 영역 사이 경계선은 끌어서 조절합니다.
- **페이지 이동**: 현재 쪽 기준 앞뒤 6쪽만 표시하고, 쪽 번호를 눌러 입력하면 그 쪽으로 이동합니다. 보기 방식은 `쪽 넘기기` / `스크롤`(위아래로 이어 읽기) 중 선택합니다.
- **빈 페이지**: 페이지 사이 어디든(`+` 버튼) 끼워 넣을 수 있습니다. 필기·녹음·자막은 쪽 번호가 아니라 페이지 고유 id에 붙어 있어 중간에 끼워 넣어도 밀리지 않습니다.
- **녹음 수정**: 구간 이름 바꾸기, 타임라인의 두 동그라미로 시작·끝 지점 자르기(원본은 보존, 언제든 다시 늘림), 삭제.
- **글자색**: 고른 색·굵기가 페이지를 넘겨도 유지됩니다.
- **실시간 자막**: 브라우저 내장 Web Speech API(한국어/English 중 하나 선택). 음성 인식 켜기/끄기와 "슬라이드에 자막 저장"을 따로 조절하며, 녹음 중 인식한 문장은 해당 녹음 구간의 시간과 연결됩니다. Chrome·Edge에서 동작하며, 음성은 브라우저 제공사의 인식 서버로 전송될 수 있습니다.

## 3차 업데이트

- **전체 녹음 1개 + 구간 표시**: 녹음 한 번이 파일 하나로 저장되고, 구간은 그 위의 [시작, 끝] 표시입니다. 하단 타임라인에서 두 동그라미를 끌어(또는 ←/→, Shift는 5초) 옆 구간 쪽으로 얼마든지 늘이거나 줄일 수 있고, `원래대로`로 처음 구간으로 되돌립니다. 타임라인의 빈 곳을 누르면 그 지점부터 이어서 들을 수 있습니다.
- **녹음 보호**: 녹음 중 5초마다 조각을 브라우저에 보관해, 창이 닫혀도 다음에 노트를 열 때 자동 복구합니다. 옛 버전(구간마다 파일이 따로인) 노트는 열 때 자동 변환됩니다.
- **홈 폴더 트리**: 왼쪽에 `G drive` / `내 컴퓨터` 스위치와 폴더 트리. 맨 위 단계는 저장 위치(내 컴퓨터에서 고른 폴더 또는 Drive 폴더)이고 그 아래 폴더는 앱에서 만들며, 저장할 때 같은 이름·구조의 실제 폴더로 만들어집니다. 폴더를 고르고 `새 노트 만들기`를 누르면 그 폴더에 바로 저장됩니다. 노트 카드의 📁로 폴더를 옮기면, Drive에 저장된 노트는 다음 저장 때 Drive 안에서도 이동합니다.
- **휴지통**: 홈 오른쪽 위 ⚙. 삭제한 노트(또는 폴더째)가 보관되며 `복원`하면 지워졌던 폴더까지 원래 위치로 되살아나고, `완전 삭제`는 이 브라우저에서 영구 삭제합니다. 녹음 자르기 기준 설정은 편집 화면 아래 녹음 줄의 ⚙로 옮겼습니다.
- **상단 접힘**: 접힌 얇은 바가 그대로 아래로 늘어나는 방식으로 변경했습니다.
